# Security Policy

This file is the default security policy for any repository under the `psanctuary` organization that
doesn't have its own `SECURITY.md`.

## Reporting a vulnerability

If you find a security issue in a project maintained under this organization, please report it
privately rather than opening a public issue, so it can be fixed before wider disclosure.

**Contact:** open a private security advisory on the relevant repository (GitHub's "Report a
vulnerability" flow under the Security tab), or reach out to Christopher Wilson, who maintains this
organization's technical infrastructure, through the contact details on his
[GitHub profile](https://github.com/drasticstatic).

Please include:
- What the issue is and where you found it
- Steps to reproduce, if you have them
- Any impact you're aware of

## Scope

This covers code and infrastructure under this organization's direct control. It's a small, early
organization, so response times may vary, but every report will be read.
